The evidence

Checks

warnPre-registration

Exploratory analysis: no pre-registered plan.

Without a plan frozen before the data existed, the metric, controls and direction may have been chosen after seeing results. Treat p-values as descriptive. Freeze one with `beatnull plan`.

warnData integrity

17 of 2160 trials missing (0.8%); rates do not differ detectably.

Missing measurements are excluded from block means, never replaced with zero: a dropped frame is not a silent response. To see whether the conclusion depends on them, every missing value is set to the least favourable measured value (low for the real condition, high for controls) and the comparison is repeated.

failReal vs controls

real does not beat: zero, random_matched (0/2 beaten).

Each control is compared with the real condition using a permutation test on block means: condition labels are reshuffled between blocks within the same group, so the test assumes nothing about distributions. p-values are Holm-adjusted across controls, and every control must be beaten.

warnUnit of analysis

A trial-level t-test would claim real beats random_matched (p = 0.046, n = 1432 trials). With blocks as the unit: p = 0.337.

Trials inside one block share a culture state, a decoder state and a stretch of time, so they are not independent. Testing trials as if they were inflates the sample size and shrinks p-values (pseudoreplication). beatnull tests block means.

warnOrder effects

Performance drifts across the run (rho = +0.71, p < 0.0001), but the schedule is balanced.

Drift affects all conditions; because positions are balanced it does not favour one condition, but it does add noise and may signal an unstable setup.

failImprovement over time

real improves across the run (rho = +0.70, p = 0.0058), but the controls improve just as much (rho = +0.61). The improvement is not specific to the real condition.

A learning curve in the real condition is only evidence of something specific to the real signal if the controls do not show the same curve. Decoders that adapt online, carried state and practice effects all improve controls too.

passInterim looks

Single planned analysis: nominal alpha applies.

If you checked results before deciding to stop collecting, declare the number of looks (--looks): stopping when p dips below alpha inflates false positives.
